# docs

開發文件目前只有繁體中文。

| 文件 | 內容 |
|---|---|
| `usage.md` | 詳細使用說明（zip 內的 `USAGE.md`） |
| `cli-json-contract.md` | CLI 與 JSON 報告契約 |
| `capability-matrix.md` | 各格式的支援範圍 |
| `decisions.md` | 規格修訂與設計決定（D、S 編號） |
| `imbc-integration.md` | IMB-C 整合方式 |
| `development.md` | 建置、測試、封包 |
| `dependencies.md`、`third-party.md` | 依賴版本與雜湊、第三方授權清單 |
| `changelog-0.x.md` | 0.x 的完整變更紀錄 |

開發期間的內部紀錄未收錄於公開 repo：開發規劃書、各階段的驗收紀錄、進度與量測紀錄、0.5.0 升級評估、IMB-C 端的開發指南，以及階段 0 的探針。`decisions.md` 中的「規劃書」與「規劃書出處」指的就是這份未公開的開發規劃書，保留原文作為歷史紀錄。支援範圍與對應的測試以 `capability-matrix.md` 為準，測試本身在 `tests/`。私人測試樣本不在 repo 內，文件中以代號表示。
